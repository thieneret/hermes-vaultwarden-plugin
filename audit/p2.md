## Context

Phase 1 (commit 63ffbec) implemented sub dir session separation:
- config.detect_process_role(): sys.argv substring detection
  (dashboard / gateway / default), case-insensitive, no env vars
- auth.resolve_process_appdata_dir(): validates base dir first via
  ensure_appdata_dir, then hardens the role subdir via
  secure_fs.ensure_hardened_directory; whitelist fallback for hostile
  roles (../../etc → default)
- __init__.py register(): resolves role + subdir, passes SUBDIR to
  BwCli(appdata_dir=...), exposes process_role/appdata_dir via PLUGIN_STATE
- status_snapshot(): includes process_role; uses getattr fallback for
  managers built via __new__ (falls back to detect_process_role())

Baseline: 832 tests pass. This phase adds the regression test suite.

## Goal

Create a comprehensive test suite verifying:
1. Process role detection correctness and robustness
2. Subdirectory resolution, hardening, and hostile-role defense
3. BwCli wiring (subdir, not base dir)
4. status_snapshot() process_role reporting (including __new__ fallback)
5. Multi-process isolation (separate subdirs → no session invalidation)

## Hard Constraints

- Do NOT modify any production code (Phase 1 already committed)
- Use only pytest and standard library (unittest.mock, tempfile, sys.argv manipulation)
- Tests must be deterministic; sys.argv must be saved/restored via fixtures
  or monkeypatch to avoid polluting other tests
- Tests must NOT require a real bw binary (mock all subprocess calls)
- Tests must NOT require network access
- Multi-process scenarios may use threading or subprocess simulation;
  real multiprocessing with tempfile isolation is acceptable if reliable
- Mock session keys must be clearly fake values
- Assert no secret values appear in any log output or file content
